# aikraft

> **Under development.** This release only reserves the package name; the SDK is not usable yet.

Privacy-first monitoring for LLM applications, for teams that need post-market monitoring under the
EU AI Act without sending production data to a third party.

## What leaves your infrastructure

Only **aggregates**: per-minute counts of latency, token and output-length buckets, and counts of
stop reasons and call statuses, per model and optional tag.

**Never sent:** prompts, responses, user identifiers, or any per-request data.
